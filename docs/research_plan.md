# 研究计划

题目：Schema 粒度对生物医学关系抽取输出的影响：正确性、信息保留与系统差异。

## 问题

分类体系变粗或变细时，抽取正确性如何变化，原有区别保留了多少；直接采用粗分类体系，与先按最细体系预测再归并，是否产生不同结果。

研究对象是给定金标准实体的关系抽取。主实验不做命名实体识别，不启用 novelty 头。

## 研究问题

- RQ0：同一目标粒度下，直接预测与细分后归并是否不同。
- RQ1：粒度如何改变正确性与标签信息保留。
- RQ2：这些变化在所选微调系统与提示系统之间是否一致。
- RQ3：显式实体类型信息是否改变上述结果。
- RQ4：金标准与模型输出相对原文存在多少欠特异、过特异或其他不一致。

BiomedBERT 与 Qwen 之间称为所选系统的比较。模型规模效应只在 Qwen3-8B 与 Qwen3-32B 之间解释。不输出唯一推荐 schema。事后用途加权只作探索性解释，不改变主评价。

## 阶段

1. BioRED 与 BC8 主实验。
2. E3 实体细分类可行性评估，安排在 BioRED 主实验之后、DrugProt 之前。本轮只建立映射检查和空表，不作人工判断。
3. DrugProt 谓词粒度扩展。

## 主产出

分类映射；直接预测与归并比较；正确性与信息保留的权衡；分类合并损失与额外预测损失；原文审计；正负极性及 DrugProt 明确上调／下调的区别保留。BioRED 的正负相关与 DrugProt 的明确上调／下调分开报告，不合并为同一种关系语义，也不计算统一准确率。

## 本轮范围

本轮建立研究定义、程序、配置和可取得语料的准备，并用合成预测完成 CPU 验证。本轮不训练神经网络，不加载预训练权重做推理，不提交 GPU 作业，不调用付费模型接口，不填写人工语义答案。

操作口径见 `docs/agreements/`。尚未确认的事项见 `docs/study_decisions.md`，不在实现中替研究者改写研究含义。
