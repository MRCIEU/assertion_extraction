# 已记录的决定与待确认事项

## 本轮已经按材料作出的决定

这些决定来自官方文件格式或研究约定，不依赖模型表现。

1. BioRED 与 BC8 的复合标识使用英文逗号分隔。一个提及保留对每个成分概念的身份关联，关系仍指向单个概念。标识 `-` 表示该提及没有概念身份，不与其他无身份提及合并。
2. 标题与摘要之间固定连接一个 ASCII 空格。BioRED 官方 BioC 显示标题与摘要之间有一个未保存的字符；空格和换行都能复现全部提及偏移。连接方式不随条件改变。
3. BC8 的 `Subject:` 行是方向注释，不是关系标签，不提供给模型，也不算标签冲突。
4. 基因–变异、基因–生物不在约定的合法类型组合中。相应金标准关系进入异常表，不临时加入合法组合。
5. DrugProt 官方训练集按文档、种子 42 划分为 2800 篇训练和 700 篇开发。官方 development 的 750 篇作为本研究评价集，划分名称为 `eval`。test-background 没有关系真值，`included_in_scoring` 为 false。
6. 上下文预算使用本地 BiomedBERT tokenizer，修订号 `e1354b7a3a09615f6aba48dfad4b7a613eef7062`。该选择与当前 Hugging Face 记录一致，但研究者尚未确认，因此输入版本保持 `proposed_not_frozen`。
7. 改名对照的显示名称是可检查的开发建议，配置状态为 `draft_pending_confirmation`。随机合并组只使用随机组名称，不赋予医学机制名称。
8. 训练与生成入口存在，但执行开关关闭。调用训练、预测或生成命令会停止，不加载权重。

## 留给研究者的问题

1. DrugProt 是否曾被用于调参。当前记录为尚未确认。
2. 官方数据与本计划不能消解的身份或类型问题：BioRED 训练集中 1 条基因–变异 Association；BC8 中指向 `-` 或文中不存在的概念的关系，以及 1 条基因–生物 Bind。
3. 精确模型与 tokenizer 修订，以及主运行训练精度。评价精度按约定为 FP32。量化尚未选择。
4. 改名对照的具体显示名称是否接受当前建议。
5. GPU 实测的授权、并发和总预算。
6. 人工审阅者，以及最终采用 400 条还是其 240 条前缀。
7. GPT 端点、固定版本和外发条件。150 英镑是未来预算上限。本轮请求数为 0。
