# 约定二：数据与输入

## 划分

BioRED 使用官方 400 篇训练、100 篇开发和 100 篇测试。BC8 使用 BioREDirect 发布中带金标准的 400 篇外部评价。测试集和 BC8 已在既往研究中查看，不称为首次接触的独立确认集。本轮只做结构、格式和候选完整性检查。

DrugProt 官方训练集 3500 篇按文档固定划分：数值 PMID 排序后，用 `random.Random(42)` 打乱，前 2800 篇为训练，其余 700 篇为开发。官方 750 篇 development 作为本研究评价集。公开 test-background 没有关系真值，不用于本地评分。研究者此前是否用 DrugProt 调参尚未确认。

## 来源

BioRED 来自 `https://ftp.ncbi.nlm.nih.gov/pub/lu/BioRED/BIORED.zip`，本地发布标识 `BIORED_2022-04-07_sha256-c3032230bd89`。BC8 金标准来自 `https://ftp.ncbi.nlm.nih.gov/pub/lu/BioREDirect/datasets.zip` 中的 `bioredirect_bc8_test.pubtator`，不用其中的 processed TSV。DrugProt 语料来自 Zenodo 5119892，指南概念 DOI 为 10.5281/zenodo.4957137。不使用来源不明的镜像。

历史代码已经删除。本轮不复用旧排除清单，也不为了贴近历史计数而删改数据。

## BioRED 候选

候选是文档级规范化概念对。同一标识的多个提及合成一个概念，不生成自身关系。无方向概念对按标识字符串排序。合法组合为疾病–基因、疾病–化学物、基因–化学物、基因–基因、疾病–变异、化学物–变异、化学物–化学物、变异–变异。各实体档和谓词档使用同一候选总体。

官方复合标识按逗号拆开，提及同时关联每个成分概念。这是身份关联的保留，不是把一条关系改派到另一个标签。`-` 不是概念标识。无标注的合法候选记为 No_Relation。完全相同的关系去重。不同阳性标签冲突、身份缺失、类型冲突和不支持的类型组合进入异常表；不任取一条标签，不静默删除，也不临时扩大类型组合。

若异常处理改变最终训练总体，数据版本不标为可正式训练。当前 BioRED 训练集因此不是可正式训练版本。

## DrugProt 候选

候选是文档内全部化学物提及与基因／蛋白提及的配对，化学物在前。不因跨句删除。同一对保留全部金标签。归并后重复的粗标签去重。

## 上下文

主实验每次处理一个候选。不同实体档、谓词档和模型共享同一段原文。不提供数据库标识、金标签、novelty 或 PMID。

策略名称为 `target_anchored_v1`：

1. 使用原始标题、摘要和可核对的字符位置。连接方式在读取器中固定。
2. 只用预先固定的 BiomedBERT tokenizer 决定 512 token 预算。
3. 全文连同必要标记在全部相关视图下都不超过 512 时，保留全文。
4. 否则在两个目标的已标注提及组合中选择覆盖两者的最短原文 token 区间；平分时取较早起点，再取较早终点。
5. 若该区间可以容纳，向左右交替扩展，每次增加一个完整原文 token。
6. 若两目标之间过长，使用围绕两个锚定提及的双片段，按左左、左右、右左、右右的顺序扩展，相遇后合并。
7. 双片段之间使用固定 `<<GAP>>`，并计入预算。
8. 目标提及不可切开。当前片段内所有完整目标提及按同一规则标记。
9. 每次预算检查取各视图编码长度的最大值，包含角色标记、GAP 和模型特殊 token。
10. 无法保留两个完整目标时记为输入异常，不自动删除。
11. 不利用关系标签、关键词或预测结果选择片段。
12. 不因为某一实体档更短而补入更多原文。

共同跨度使用交错边界标记，原文只出现一次。重叠表示名称为 `interleaved_boundary_tags_v1`。

当前 tokenizer 尚未由研究者确认。程序和合成测试可以完成；真实输入版本保持待确定，不改为另一个 tokenizer 后宣布冻结。
