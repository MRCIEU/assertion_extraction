# 约定四：评价与审计

评价分三层：当前粒度金标准上的任务正确性；相对最细金标签的信息保留；相对人工原文参照的语义保真。主总体是完整候选集合。

## 正确性

报告阳性 micro-precision、recall、F1，每类 precision、recall、F1，macro-F1，全候选完全正确比例，有效输出覆盖率和失败数量。TP、FP、FN 先在候选内按标签集合匹配，再加总。BioRED 的错类同时产生一个 FP 和一个 FN。No_Relation 不作为阳性类进入 micro-F1。

分母为零时，precision 和 recall 为 null，并注明 undefined。F1 的主实现在 `2TP+FP+FN` 为零时记 0。macro-F1 使用固定的全部阳性类别，不删除零支持类别，同时报告每类支持数。

输出计数：

- 正常空列表是有效 No_Relation。
- 缺失或无法解析：没有可用预测；阳性金标签计 FN；完全正确为 false。
- BioRED 多个不同标签：整条拒绝，计一个无效输出 FP，全部阳性金标签计 FN。
- DrugProt 的非法标签保留合法标签，每个不同非法标签计一个额外 FP。BioRED 若不能构成唯一合法单标签，按无效输出处理。
- 非法标签不加入医学 schema。额外 FP 进入总体运行评价，并另表报告。因此合法类别 FP 之和不必等于总 FP。
- 同时出现无关系声明和阳性标签时拒绝。

失败不从信息保留或全候选正确率的分母中删除。

## 信息保留

只使用拟合训练集的细标签计数，每细类加 1 后归一化。多标签语料按金关系计数。`IC(G)=-log p(G)`，父组概率为成员之和。细金标签属于预测组时，保留分为 `IC(G)/IC({g})`，否则、漏检或失败时为 0。DrugProt 对每条细金关系取覆盖它的合法预测组中的最高值。额外错误标签由 precision 惩罚，不改变保留分。

P1 的类别区别保留为 0，检测价值另行报告。频率无关版本在细标签属于预测组时为 `1-log(|G|)/log(K)`，否则为 0。

`C_s` 是全部细金标签正确映射到该档后的平均分，`R_s` 是模型实际平均分。损失分解为 `1-R_s=(1-C_s)+(C_s-R_s)`。这不是原文全部语义的分解。

## 极性

分别统计正确保留、反转、无极性粗化、漏检和冲突。DrugProt 同时输出相反方向时记为冲突。金标准本身包含两种方向时单独比较集合，不指定单一方向。不计算没有真值支持的因果存活率。

## 汇总

每个微调种子先计算完整指标，再取三个种子的算术平均。不先合并预测或概率。配对差先在同一种子的条件之间计算，再取均值。bootstrap 抽取文档并保留该文档的全部候选；在同一次抽样上重算各种子指标，再平均并求条件差。使用 2000 次、种子 100、百分位 95% 区间。审阅抽样种子仍是 20261115。bootstrap seed=100 由研究者确定，当前继续采用。第二轮把 bootstrap 种子从上一轮记录的 20261115 改为 100。区间条件于已经训练的模型，不重抽训练种子。默认报告效应量和区间，不做显著性检验。

## 审阅

50 条训练案例用于形成规则，另 50 条独立案例用于检查。最终主方案为 test 与 BC8 各 Association 100、其他阳性 60、No_Relation 40，合计 400。回退为同一随机序列的前缀，每数据集 60、36、24，合计 240。分层随机种子为 20261115。是否回退在查看答案之前按时间决定。

其他阳性层在该层内随机抽取，不按预测表现挑选。候选不足时不改比例，只报告实际支持。最终样本的 25% 安排双人独立审阅。无法安排第二人时如实记录；同一人复核不是双人一致性。

第一轮材料展示全文和两个目标，不展示金标签与模型预测。先记录存在性、具体关系、极性、条件、不确定性和无法判断，再比较金标签和输出。本轮只生成规则、抽样和空表，不代填答案，不调用 GPT。

审计主分析分别报告欠特异、过特异、其他不一致和无法判断。不预设过特异罚两倍，也不自动把原文更具体当成标注错误。
