# 约定三：模型实验

## 路线

直接预测使用目标谓词档训练或提示。归并只映射已经保存的 P4 离散预测。不重新调用模型，不改阈值，也不把概率相加后分类。

## 主矩阵

BioRED：BiomedBERT 为 3 个实体档 × 4 个谓词档 × 3 个种子，共 36 次训练。Qwen3-8B 与 Qwen3-32B 各 12 组。32B 的 E2 改名和随机合并共 5 组，状态为待确认草稿。

DrugProt：BiomedBERT 为 4 个谓词档 × 3 个种子，共 12 次训练。两个 Qwen 各 4 组。DrugProt 不设实体档因子。

主微调共 48 次。本轮只生成 `experiment_table.tsv`，不运行。

## 微调

种子为 13、42、2026。学习率 2e-5，最多 10 个 epoch，有效 batch size 16，warmup 为总步数的 10%。AdamW 的 betas 为 (0.9, 0.999)，epsilon 为 1e-8，weight decay 为 0.01；bias 和归一化参数不衰减。梯度裁剪范数为 1.0。编码器 dropout 使用预训练配置，分类头 dropout 为 0.1。warmup 后线性衰减学习率。不使用 novelty 头、类别加权或额外负样本抽样。

BiomedBERT 使用 CLS 表示，经 dropout 和线性分类头。BioRED 为包含 No_Relation 的单标签 softmax 与标准交叉熵，推理取 argmax。DrugProt 每个阳性标签一个 sigmoid，损失为按样本和标签平均的 BCEWithLogitsLoss；无关系候选的目标全为 0。

全部实体档共用 tokenizer 和标记词表。同一种子共用编码器初始参数、标记嵌入初始化和样本顺序。不同谓词档的分类头维度不同，不宣称权重相同；分类头使用独立、可记录的随机数流。数据顺序随机数与模型初始化随机数分离。

训练精度在模型冒烟测试前确定，随后所有主条件统一。评价使用 FP32。本轮精度尚未确定。

BioRED 按当前谓词档开发集阳性 micro-F1 选模，平分取较早 epoch。DrugProt 在每个 epoch 搜索 0.05 到 0.95、步长 0.05 的共同阈值，取开发集 micro-F1 最优，平分取较高阈值，再取较早 epoch。P4 归并沿用 P4 已确定的阈值。保存 best 和 last。

## 提示

模型为 Qwen3-8B 与 Qwen3-32B。本轮记录的修订号分别是 `b968826d9c46dd6066d109eabc6255188de91218` 和 `9216db5781bf21249d130ec9da846c4624c16137`，状态为建议、未冻结。不下载权重。

计划中的生成设置为 temperature 0、top_p 1、max_new_tokens 256，并关闭思考模式。官方 generation config 中的采样设置不是本研究设置。兼容性尚未实测；不支持的参数不静默替换。

统一输出为 `{"candidate_id":"...","labels":[...]}`。labels 只允许当前档阳性标签。无关系输出空列表。BioRED 阳性恰好一个标签。DrugProt 可以多个。不输出 No_Relation 字符串，不生成 novelty、解释或证据句。

同一 Qwen 模型的全部主条件使用相同精度和量化设置。量化未确定时不自动选择。

## 失败与补充

基础设施故障最多同配置重试两次。有效回答不因结果差而重跑。只做固定的代码围栏去除，不用另一个模型修改答案。

E3 与降采样有独立配置，不自动启动。降采样三组为完整数据、各阳性粗类限量、以及与限量组阳性总数相同的按比例抽样。限量为八个细类训练计数均值向下取整。No_Relation 不变。该分析只提供解释线索。DrugProt 替代分组可以事后归并已有 P4 输出；直接训练需要另批预算。
