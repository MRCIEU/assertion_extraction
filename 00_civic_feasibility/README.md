# Step 00 — CIViC feasibility

Pulls accepted CIViC evidence via GraphQL and asks whether enough PubMed-backed, two-entity targets exist for a ranking study.

**Run result:** 4,856 accepted evidence items; 4,674 evaluable abstract-level two-entity targets; **2,074 abstract-grounded pairs** (both entities in the abstract, 44.4%). Of those, **1,812 gene–drug and gene–disease pairs** are frozen as the evaluable ranking set in step 02 (262 variant pairs are excluded — they cannot be ranked). ~89.8% of evaluable items are positive assertions (SUPPORTS), motivating ranking/triage rather than binary classification.
