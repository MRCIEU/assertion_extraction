# Schema granularity changes what a relation extractor keeps and what it gets right

A relation-extraction benchmark scores a model against one fixed label set. A coarser or finer schema is a different task, and a coarse label can be produced either by asking for it directly or by mapping a finer prediction onto it. This repository implements that comparison for biomedical relation extraction with the entities given. BiomedBERT is fine-tuned from one fixed checkpoint. Qwen3-8B and Qwen3-32B use one frozen instruction. BioRED varies the entity level and the predicate level and is also scored on BC8. DrugProt varies the predicate level only. The fine-tuning matrix is 48 runs across three seeds. The prompt matrix is 1,793,840 unique requests. Predictions at the finest predicate level are mapped onto the coarser levels without another model call and without a new threshold. The primary score is positive micro-F1 on the full candidate set, with an information-retention score against the fine gold labels. There is no human reading of the source text in this repository, so the retention score is not a claim about semantic fidelity.
